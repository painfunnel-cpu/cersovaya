# Violet Bloom — Vercel static build

Корневой файл — `index.html`. Архив содержит сжатые изображения в `assets/`, каждый JPG оптимизирован для загрузки через GitHub.

Vercel: Framework Preset Other, Root Directory пусто или `.`, Build Command пусто, Output Directory пусто.

Переменные Vercel: `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
